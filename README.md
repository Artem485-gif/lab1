# Лабораторна робота №1
Тема: Налаштування середовища розробки: VS Code, Live Server, DevTools. Контроль версій та публікація статичного сайту.
Мета: Сформувати робоче середовище, у якому виконуватимуться всі наступні лабораторні роботи курсу, та засвоїти базовий цикл роботи розробника клієнтської частини: локальна розробка → перевірка результату →  контроль версій →  публікація.

## Опис проєкту:
Цей проєкт є виконанням першої лабораторної роботи, присвяченої налаштуванню сучасного середовища розробки вебзастосунків (VS Code, Live Server, DevTools) та оволодінню базовими навичками роботи з системою контролю версій Git.
